# MethaNor project status

**Release:** V4.2 Publication QA Release  
**Status:** functional, source-traceable conceptual screening software with automated validation

## Completed

- Final EN/ES publication QA with technical terminology standardized and no scientific/functional changes.
- Bilingual EN/ES static web application.
- Independent Python reference engine.
- Energy-conservation correction and 15 MW audit.
- Real-coordinate interactive map with satellite/map context, coordinate-centred markers, arbitrary point selection, centre/copy controls and external source links.
- Technology/vendor shortlist for electrolysis, methanol synthesis, DAC and water treatment.
- A/B/C technology comparison using only public fields; missing vendor data remain explicitly missing.
- Executive decision snapshot linking physics, site evidence, technology evidence and economics.
- Per-category technology configuration with no fabricated price/performance values.
- Thesis-derived mass and space budget.
- Site / P2X / technology / platform / build & operations / risk / economics / methodology / evidence / origin flows.
- Break-even solver, sensitivity analysis and A/B/C scenario comparison.
- Concept risk matrix and design-decision log.
- Source registry with evidence class, variables, module usage, access-date governance and bilingual use descriptions.
- Transparent Portfolio Fit score weights surfaced directly in the UI.
- Automated unit/repository/V4.2 tests plus JavaScript syntax gate.

## Explicitly outside scope

- bankable energy-yield assessment;
- class-approved naval design;
- CFD/RAO/FEA/fatigue/mooring-dynamics validation;
- HAZID/HAZOP and hazardous-area classification;
- vendor-guaranteed process package or commercial quotation;
- environmental impact assessment;
- official GIS permitting conclusion;
- AIS-based navigational risk conclusion without a licensed dataset;
- investment recommendation.
